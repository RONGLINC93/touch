# 触摸屏工具(Windows)

两个零第三方依赖的小工具(仅标准库: tkinter + PowerShell + schtasks)。

| 文件 | 用途 |
| --- | --- |
| `map_touch.py` | **触摸映射**:触摸副屏时光标却动在主屏 → 把触摸输入绑定到副屏 |
| `touch_toggle.py` | **触摸开关**:一键/热键 启用或禁用触摸屏 |

## 一、把触摸响应到副屏(map_touch.py)

### 适用场景

两台显示器,触摸屏是副屏,但触摸事件却落在主屏上。

### 原因

Windows 需要"标识"哪个触摸输入设备(数字化仪)对应哪台显示器。没做过这个标识(或多屏接插顺序变化后标识失效),触摸坐标就会全部映射到主屏。

### 使用

```powershell
python map_touch.py
```

首次运行弹一次 UAC(系统的 `MultiDigiMon.exe` 向导需要管理员权限),点"是"。完整流程:

1. 点 **"标记触摸屏"** — 每块屏幕出现全屏大编号,用手指触摸你的触摸屏,看点亮的是哪块(错位时点亮的是主屏),按 Esc 结束
2. 点 **"开始映射向导(推荐)"** — 屏幕会全屏变蓝;工具自动帮你在非触摸屏上按 Enter 跳过(本机 2 台显示器 = 自动按 1 次)
3. 提示出现在副屏(触摸屏)上时,**用手指触摸该屏幕**,完成绑定
4. 再点一次"标记触摸屏"验证:这次触摸应该点亮副屏

窗口里会列出当前所有显示器(主/副屏、分辨率、桌面位置、触摸命中结果)和检测到的触摸设备,方便确认哪台是副屏。

### 先标记:哪台是触摸屏、当前映射到哪

点 **"标记触摸屏"**:每块屏幕铺一个全屏大编号(屏幕 1 / 屏幕 2 …),**用手指触摸你的触摸屏**,被点亮的那块就是 Windows 当前映射的目标——错位时点亮的是主屏。触摸顺序会记录到列表的"触摸命中"列,结束时会给出诊断和下一步建议。按 Esc 随时结束。

### 其他按钮

- **平板电脑设置**:系统自带的"平板电脑设置"面板,可手动点"设置"做同样的事,或点"校准"修正触摸偏移(点左边反应到右边这类问题)
- **显示设置**:检查两台显示器的排列位置是否和实际摆放一致——不一致也会造成触摸错位;另外显示模式必须是"扩展",不能是"复制"

### 原理

调用 `%SystemRoot%\System32\MultiDigiMon.exe -touch`(系统触摸标识向导),用 `EnumWindows` 找到它的窗口并 `SetForegroundWindow` 聚焦,再通过 `keybd_event` 发送 Enter 跳过非触摸屏,最后留给你在触摸屏上完成标识。

### 常见问题

- **提示"找不到 MultiDigiMon.exe"**:系统文件缺失,用"平板电脑设置"按钮手动完成
- **向导没反应/窗口没出现**:UAC 是否点了"是";或改用"平板电脑设置"
- **做完映射触摸反而完全失灵**:进"平板电脑设置"重新做一次标识
- **部分便携触摸显示器/数位板有自己的厂商控制面板**:先升级/安装其官方驱动,再做标识

## 二、触摸屏快速开关(touch_toggle.py)

```powershell
python touch_toggle.py        # 一键切换所有触摸屏
pythonw touch_toggle.py       # 无控制台窗口
python touch_toggle.py --mini # 迷你模式(小置顶窗)
```

- 全局热键 `Ctrl+Alt+T` 随时切换(开的全部关、关的全部开)
- 自动排除触摸板/鼠标/键盘,只操作触摸屏
- 可设置开机自启(任务计划,最高权限)

设备识别规则:FriendlyName 匹配 `touch|digitizer|触摸|触控|手写`(兼容中文系统,如"符合 HID 标准的触摸屏"),或硬件 ID 含 `HID_DEVICE_UP:000D_U:0004`(HID Touch Screen 用法页,可识别名字里没有 touch 的 USB 触摸控制器)。

## 运行要求

- Windows 10 / 11
- Python 3.8+([python.org](https://www.python.org) 下载,安装时勾选 "Add python.exe to PATH")
